# Снимок источника NYC 311

Издатель NYC Office of Technology and Innovation
[Страница набора](https://data.cityofnewyork.us/Social-Services/311-Service-Requests-from-2020-to-Present/erm2-nwe9)
[Условия использования NYC Open Data](https://www.nyc.gov/home/terms-of-use.page)

Файл `nyc311_manhattan_2025-01.csv` скачан 2026-10-14 по HTTP
Срез содержит 61 331 обращение в Манхэттене за январь 2025 года
После скачивания байты файла не изменялись

## Почему выбраны 8 полей

В Project Brief описана выгрузка из 15 полей размером около 16 МБ
ЛР № 2 требует небольшой файл, который можно хранить в Git
Поэтому в запросе к Socrata оставлены 8 полей для подсчёта обращений, времени закрытия,
доли незакрытых записей и срезов по теме, агентству, дню, часу и каналу подачи

Период и число обращений сохранены, выгружен весь январь без сокращения строк
Размер файла уменьшился до 7,2 МБ за счёт выбора столбцов у источника
DAG не обрезает файл и сохраняет HTTP-ответ без изменений
Исходный Project Brief ЛР № 1 сохранён в `docs/project_brief.md`

## Воспроизведение

Точный URL находится в `source_url.txt`, размер и SHA-256 в `manifest.json`
Набор обновляется ежедневно, поэтому новая выгрузка может отличаться от этого снимка

DAG скачивает основной HTTP-источник и не читает этот файл
Снимок хранится в Git для ручного fallback на URL GitHub, закреплённый за commit SHA
При fallback нужно также поменять host HTTP Connection и пересоздать сервисы Airflow
